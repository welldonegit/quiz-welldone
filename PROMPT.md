# Промт для Claude Code

> Скопіюй текст нижче в Claude Code. Перед цим поклади папку `wd-quiz/` (весь цей пакет) у корінь проєкту сайту.

---

Звертайся до мене українською.

Зверстай інтерактивний квіз-форму для маркетингової агенції well done за готовим дизайном. Дизайн, тексти й логіка вже затверджені — твоя задача перенести їх у продакшн-код максимально точно до макетів, без власних змін текстів чи структури.

## Матеріали (папка `wd-quiz/`)

- `SPEC.md` — повне ТЗ: порядок екранів, поведінка, маска телефону, валідація, payload заявки, аналітика, доступність. **Прочитай повністю перед початком.**
- `content/quiz-content.json` — усі тексти, варіанти відповідей, коментарі експерта, кейси по сферах. Це єдине джерело правди для контенту: тексти не хардкодь у розмітці, рендери їх з цього файлу (або з JS-модуля, згенерованого з нього).
- `design/screens/` — еталонні скріни всіх 12 екранів: `mobile-*.png` (390×844 @2x) і `desktop-*.png` (1280×800 @2x). Звіряй з ними кожен екран.
- `design/tokens.css` — кольори, радіуси, тіні, розміри, анімації.
- `prototype/prototype-mobile.dc.html`, `prototype/prototype-desktop.dc.html` — робочий прототип з дизайн-інструменту. Синтаксис (`<x-dc>`, `<sc-if>`, `{{…}}`) — НЕ для продакшну, але в ньому точні inline-стилі (відступи, розміри, шрифти) і вся логіка в класі `Component` (переходи, маска телефону `fmtPhone`, валідація, персоналізація). Використовуй як довідник.
- `assets/` — логотип, 24 SVG-іконки, фото (превʼю; оригінали — у `assets/image-sources.md`).

## Як працювати

1. Спочатку вивчи проєкт: стек, збірку, структуру, наявну дизайн-систему (на сайті є `colors_and_type.css` і self-hosted шрифти Inter). Квіз має органічно вписатися в проєкт. Якщо явного стеку немає — роби на vanilla HTML + CSS + JS (ES-модулі), без фреймворків і без важких залежностей.
2. Оформи квіз як незалежний компонент: власні класи з префіксом `wdq-`, стилі не мають ламати сторінку й не мають залежати від глобальних стилів сайту.
3. Підтримай два режими підключення:
   - вбудована секція: `<div data-wd-quiz></div>`;
   - модальне вікно на весь екран, яке відкривається будь-якою кнопкою з атрибутом `data-wd-quiz-open` (закриття: хрестик, Esc; блокування скролу сторінки; повернення фокусу).
4. Конфіг в одному місці: `QUIZ_CONFIG = { submitUrl, storageKey, autoAdvanceMs: 380, debug }`.
5. Якщо не знаєш, куди відправляти заявки (webhook / CRM / Telegram через бекенд) — **запитай мене**, а поки зроби адаптер з `submitUrl` і заглушкою, що логує payload у консоль у debug-режимі. Жодних секретів (токенів ботів, API-ключів) у фронтенді.
6. Шрифт: тільки Inter з кирилицею. Якщо на сайті немає ваги 600 — підключи її або заміни на 700, але скажи мені, що обрав.

## Вимоги до якості

- Pixel-perfect відповідність скрінам на 390px і 1280px; коректна поведінка на 360px, 768px, 1024px, 1440px. Без горизонтального скролу.
- Mobile: липкий футер з кнопками «Назад» + основна дія, з урахуванням `safe-area-inset-bottom`; основна кнопка першого екрана видима без прокрутки.
- Повна робота з клавіатури, `:focus-visible`, ARIA за `SPEC.md`, `prefers-reduced-motion`.
- Lighthouse (mobile) для сторінки з квізом: Performance ≥ 90, Accessibility ≥ 95. Зображення у WebP/AVIF зі `srcset` і `loading="lazy"` (крім першого екрана).
- Жодних помилок у консолі.

## Перевірка перед здачею

Пройди квіз повністю мінімум трьома сценаріями й покажи мені скріни (Playwright) mobile + desktop:

1. Нерухомість → кілька проблем → бюджет «$3 000 – 10 000» → посилання заповнені → Telegram з `@username`.
2. «Інша сфера» з вписаним текстом → «Потрібна рекомендація» → посилання пропущені → Viber з номером, введеним як `0671234567` (має стати `+380 67 123 45 67`).
3. Будь-яка сфера → дійти до контакту → двічі «Назад» → змінити відповіді → «Зателефонувати» → спроба надіслати неповний номер (помилка) → виправити → успіх.

Також перевір: оновлення сторінки посеред квізу відновлює крок і відповіді; зміна сфери змінює кейси; UTM з URL потрапляють у payload; події `dataLayer` відправляються.

Після цього коротко напиши, що зроблено, де лежать файли, як підключити квіз на сторінку і що потрібно від мене (endpoint для заявок, фото ЖК «Янтарний»).
