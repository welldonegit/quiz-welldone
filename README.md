# Пакет для верстки квізу well done

1. Розпакуй архів і поклади папку `wd-quiz/` у корінь проєкту сайту.
2. Відкрий проєкт у Claude Code.
3. Скопіюй текст із `PROMPT.md` (усе під рискою) і надішли як перше повідомлення.

Склад:

```
wd-quiz/
├── PROMPT.md                 промт для Claude Code
├── SPEC.md                   ТЗ: сценарій, логіка, маска, payload, аналітика
├── content/quiz-content.json усі тексти й дані квізу
├── design/
│   ├── tokens.css            кольори, радіуси, тіні, шрифт
│   └── screens/              24 скріни: 12 mobile + 12 desktop
├── prototype/                робочий прототип (довідник логіки й стилів)
└── assets/                   лого, 24 іконки, фото + image-sources.md
```

Що підготувати заздалегідь:
- куди надходитимуть заявки (CRM, webhook Make/n8n, Telegram через бекенд) — Claude Code про це запитає;
- фото або рендер ЖК «Янтарний» (єдиний кейс без фото).
